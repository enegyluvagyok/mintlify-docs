Az Analyse platform MySQL 9.1\+ adatbázist használ (fejlesztésben), éles környezetben MySQL 8.0\+ ajánlott. Az összes tábla `utf8mb4_unicode_ci` karakterkészlettel kerül létrehozásra. Ez a dokumentum az aktuális sémát írja le a phpMyAdmin SQL dump alapján (2026-05-17).

<Warning>
  Az adatbázis jelenleg **MyISAM** motort használ a legtöbb táblánál. Éles környezetben az **InnoDB** motor erősen ajánlott a tranzakciókezelés, külső kulcsok és összeomlás-biztonság miatt. Lásd: [Adatbázisra vonatkozó követelmények](#adatbazisra-vonatkozo-kovetelmenyek).
</Warning>

## Adatbázisra vonatkozó követelmények

### Szerver és verzió

| Követelmény | Érték |
| --- | --- |
| Ajánlott motor | **InnoDB** (tranzakciók, FK, crash recovery) |
| Jelenlegi motor | MyISAM (fejlesztési dump) |
| Minimális verzió (éles) | MySQL 8.0\+ |
| Fejlesztési verzió | MySQL 9.1.0 |
| Karakterkészlet | `utf8mb4` |
| Collation | `utf8mb4_unicode_ci` |
| Időzóna | UTC (`+00:00`) |

<Warning>
  Az összes tábla átállítása InnoDB motorra éles telepítés előtt **kötelező**. A MyISAM nem támogat tranzakciókat és idegen kulcsokat — egy sikertelen adatbázis-művelet részleges adatkárosodást okozhat. Az átállítandó táblák listájához futtasd:

  ```sql
  SELECT CONCAT('ALTER TABLE `', TABLE_NAME, '` ENGINE=InnoDB;')
  FROM information_schema.TABLES
  WHERE TABLE_SCHEMA = 'analyse' AND ENGINE = 'MyISAM';
  ```
</Warning>

### InnoDB konfiguráció

```ini
# /etc/mysql/mysql.conf.d/mysqld.cnf
[mysqld]
default_storage_engine        = InnoDB
innodb_buffer_pool_size       = 8G        # RAM 50-70%-a (pl. 16 GB RAM esetén)
innodb_buffer_pool_instances  = 4         # buffer_pool_size / 1 GB
innodb_log_file_size          = 512M
innodb_flush_log_at_trx_commit = 1        # ACID megfelelés
sync_binlog                   = 1         # Replikáció esetén
character_set_server          = utf8mb4
collation_server              = utf8mb4_unicode_ci
```

### Mentési stratégia

- **Napi teljes mentés:** `mysqldump --single-transaction --routines --triggers analyse > backup_$(date +%F).sql`
- **Növekményes mentés:** Percona XtraBackup (InnoDB bináris szintű)
- **Binlog:** `binlog_format=ROW` ajánlott replikációhoz és PITR-hez
- **Megőrzési idő:** Minimum 30 nap helyi \+ offsite
- **Tesztelés:** Havi mentés-visszaállítási teszt külön szerveren
